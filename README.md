# Ancient Empires Reloaded (Google Play reference)

This repository tracks the **official Google Play Android package** for `net.toyknight.aeii.android` for comparison and reverse engineering.

- Official Google Play listing: https://play.google.com/store/apps/details?id=net.toyknight.aeii.android
- Game developer/source: https://github.com/AncientTree/project_aeii
- Original project README states its code is **GPL-3.0** and permits use of its game assets.
- The APK is downloaded directly from Google Play, **not** a modded APK or third-party repack.
- The downloaded package's version, SHA-256 hash and signing certificate are recorded beside the APK.
- Google Play may deliver a base APK plus device-specific split APKs; keep all files together.

## Update

The GitHub Actions workflow **Fetch Google Play APK** runs when first added, or can be run manually from the Actions tab. It does **not** run on a schedule.

Binary files are not modified. The upstream repository and its licence should be consulted before making derivative distributions.
